# 学习强国"习近平文汇"采集实战手册

本手册记录实测验证过的技术细节与纪律，采集前必读。

## 一、防风控纪律（不可妥协）

学习强国前端为阿里云 WAF 防护，按 TLS 指纹识别非浏览器流量。纪律如下：

1. **只用真浏览器**：DrissionPage `ChromiumPage()` 接管本机真实 Chrome（用户已登录态）。绝不直接 requests/curl 访问页面或盲试 API 参数——盲试返回 INVALID_PARAM，密集探测会导致 IP 被封。
2. **单线程**：一次只开一个检索词、一页一页翻。禁止并发。
3. **人类节奏**：翻页间 `time.sleep(random.uniform(4, 9))`；词与词之间 5–12 秒；每页先做 2–4 次随机幅度滚动再点下一页。
4. **验证码挂起**：检测到"验证码/安全验证/滑动验证/访问异常"字样时，打印提示并循环等待人工在浏览器完成（最多约 2 分钟），通过后继续，绝不重试绕过。
5. **断点续传**：每个检索词一个子目录存原始 JSON；目录非空即跳过。重采需手动删目录。
6. **沙箱环境**：在 WorkBuddy 沙箱内运行时，本机代理环境变量会干扰 DrissionPage 连接 Chrome 调试端口，用 `env -u http_proxy -u https_proxy -u all_proxy python ...` 绕过。
7. **403/异常退避**：某词异常时跳过该词继续（脚本的 try/except 已处理），整体失败时停止而非加速重试。

## 二、检索页与 API 结构

- 检索页 URL：`https://static.xuexi.cn/search/online/index.html?query=<词>&page=1`
- 频道切换：检索结果页有多个 tab（综合/视频/文汇/…）。**"习近平文汇"必须用 JS 点击 `[role="tab"]` 中 textContent 含"文汇"的元素**，改 URL 参数切不了频道。
- 数据截获：`page.listen.start("api/search")` 后点击 tab，`page.listen.wait(timeout=25, fit_count=True)` 截获 JSON。翻页点击 `a.page-next`（CSS 选择器 `.page-next`）后再次 wait。
- 响应结构（文汇频道）：
  ```
  data.total        总条数
  data.pages        总页数
  data.list[]       卡片数组，每卡片:
    biz_id          条目唯一 ID（跨页去重键必须用它）
    cardSchema.renderData:
      title         讲话场合（如"习近平2012年11月15日在党的十八届一中全会上的讲话"）
      summary       原文段落（含高亮 <em> 标签，解析时需去 HTML 标签）
      publish_time  日期
      url           原文链接
      ext_infos[]   所属文献（如《习近平谈治国理政》卷册）
  ```

## 三、已知坑

| 坑 | 正确做法 |
|---|---|
| 按标题去重 | **必须用 biz_id**。同篇讲话的不同段落标题相同，按标题去重会在第一页后误判"无新数据"提前终止 |
| `markdown.text` 字段 | 不可用——按竖排/版式切碎，质量差；只用 `renderData.summary` |
| summary 中的 `<em>` | 检索词高亮标签，解析时用 `re.sub(r"<[^>]+>", "")` 去除 |
| CSV 被 Excel 占用 | 写入前 try PermissionError，自动换带时间戳的文件名 |
| 早期文献日期 | publish_time 可能只有年月（如 `1984-12`）甚至只有年份，排序与格式化需兼容 1–3 段 |
| 泛词命中爆炸 | "带头/表率/榜样"等泛词单词条目可达数百条，误命中率高，放最后采集 |

## 四、检索词表设计（按层级穷尽）

为穷尽某一主题论述，检索词按六层设计（示例为"以上率下"主题）：

1. **核心表述**：以上率下、率先垂范、以身作则、身先士卒…
2. **行为层**：带头示范、领导带头、向我看齐、从我做起…
3. **主体层**：关键少数、高级干部、一把手、领导机关和领导干部…
4. **机制层**：一级带一级、层层传导、层层压实、上下贯通、上行下效…
5. **典故层**：子帅以正、其身正、善禁者、正人先正己、己不正、上梁不正、下必甚焉、破窗效应…
6. **泛词层**（最后跑，量大误命中多）：带头、表率、标杆、榜样、领导干部…

词表为纯文本，每行一词，`#` 开头为注释。

## 五、下游：语义标注（机械去重之后）

机械去重（`dedup_items.py`）只处理确定性重复，语义去重必须由模型逐条判定，禁止用正则/机械规则代劳。实测有效的五档标注体系：

| 档位 | 判定标准 |
|---|---|
| 核心论述 | 讲定位、机制、道理的原文（如"善禁者，先禁其身而后人"的道理阐释） |
| 要求部署 | 对领导干部的指令性要求（带头、当好第一责任人…） |
| 语境提及 | 关键词出现但非本主题语义（如表彰词里的"标杆"、外交语境"表率"） |
| 反面警示 | 负向现象剖析（上热中温下冷、层层失守…） |
| 无关 | 纯关键词误命中 |

操作要点：分批（每批约 120 条）落盘标注文件，用 jsonl 持久化进度（id→标注），支持中断续标；样例批先让用户审核尺度，认可后再全量铺开。短引文（≤2 字）命中判"保留待复核"而非直接剔除；典故类词条误命中率最高（实测约 2/3 无关）。

## 六、完整流程命令示例

```bash
# 1. 采集（先小词验证，再全词表）
python xuexi_wenhui.py --test --out ./学习强国JSON/文汇
python xuexi_wenhui.py --all --words-file 词表.txt --out ./学习强国JSON/文汇

# 2. 解析建表
python parse_wenhui_json.py --src ./学习强国JSON/文汇 --prefix 05_

# 3. 机械去重
python dedup_items.py 05_条目总表.csv 08_去重后待标注.csv

# 4. 语义标注（模型分批逐条判定，进度持久化，最终按档位出工作底稿）
```
